# pjournal — 个人日记终端应用

> 一款基于 Python curses 的终端个人日记工具，支持写作提示、AI 提示词生成、Flomo 同步和 WebDAV 双向同步。这是基于 https://github.com/shmimel/bee-write-back.git 这个项目里面的journal这个软件的改版，我将其改成了中文版，并且添加了三种主要功能：将日记内容发送到flomo，并自动添加日记标签；调用deepseek的api，结合个人经历和爱好，让ai生成日记提示词；webdav同步功能。

## 功能特性

- **终端原生界面** — 基于 curses 的全键盘操作，零鼠标依赖
- **中文完美支持** — CJK 字符宽度自动计算，中文排版正确对齐
- **200+ 内置提示词** — 涵盖感恩、创造力、自我关怀、目标设定、情绪等 20+ 主题
- **AI 智能提示词** — 接入 Deepseek API，根据个人经历和爱好生成定制化写作提示
- **双向 WebDAV 同步** — 基于文件修改时间的双向同步，支持删除传播，保持本地与远程一致
- **Flomo 笔记同步** — 一键将日记发送到 Flomo，自动添加 #日记 标签
- **周追踪器** — 可视化本周每日写作状态（✓ 已写 / · 未写）
- **连续写作统计** — 自动计算连续写作天数和总篇数
- **纯文本存储** — 日记以 `.txt` 格式保存，无锁定，随时可用其他工具打开
- **自动换行编辑** — 支持长文本自动折行、光标精确定位
- **轻量无依赖** — 仅使用 Python 标准库，无需安装第三方包

## 快速开始

### 环境要求

- Python 3.8+
- 终端需支持 UTF-8 编码和 curses（Linux/macOS 自带）

### 运行

```bash
# 克隆或下载 pjournal.py
chmod +x pjournal.py
./pjournal.py

# 或直接运行
python3 pjournal.py
```

无需安装任何依赖，所有功能开箱即用。

## 使用指南

### 主界面

启动后将看到主界面，包含以下区域：

```
              个人日记

    [一]  [二]  [三]  [四]  [五]  [六]  [日]
     ✓    ✓    ·             

       连续: 3 天  ·  总计: 42 篇

       ✓ 今日已写 2 篇

       [p] 提示写作
       [f] 自由写作
       [v] 查看过往日记
       [w] 同步到WebDAV
       [s] 设置

       [q] 退出
```

- **周追踪器**：`[三]` 表示今天，`✓` 表示该日有日记，`·` 表示该日无日记
- **统计信息**：显示连续写作天数和总篇数
- **今日状态**：显示今天已写的日记篇数

### 写作模式

#### 提示写作 `[p]`

从 200+ 内置提示词中随机选择一个，作为写作灵感。提示词显示在编辑区顶部，以淡色标注。

#### 自由写作 `[f]`

无提示词，自由发挥。

#### 编辑器操作

进入编辑器后，即可开始写作。编辑器支持：

- 多行文本编辑
- 自动换行显示
- 中英文混排光标定位
- Tab 缩进（4 空格）
- 光标行/列位置显示
- 实时字数统计

### 查看过往日记

按 `[v]` 进入日记列表，显示所有历史条目，最新在前。每条显示日期和内容预览。

- **↑/↓ 或 j/k**：上下选择
- **Home/End**：跳到第一/最后一篇
- **回车**：打开阅读
- **[d]**：删除选中日记（需确认）
- **Ctrl+S**：发送选中日记到 Flomo
- **[q]**：返回主界面

#### 阅读模式

打开日记后进入只读分页器：

- **↑/↓ 或 j/k**：逐行滚动
- **Space / PageDown**：向下翻页
- **PageUp**：向上翻页
- **g**：跳到顶部
- **G**：跳到底部
- **Ctrl+S**：发送到 Flomo
- **q**：返回列表

### 设置界面

按 `[s]` 进入设置，分为四个分组：

```
 ── AI ──
 Deepseek API Key:  sk-xxxxxxxx

 ── Flomo ──
 邮箱:    user@example.com
 密码:    ••••••••

 ── WebDAV ──
 服务器地址:  https://dav.example.com
 用户名:    myuser
 密码:      ••••••••

 ── 个人 ──
 经历:    软件工程师，5年开发经验
 爱好:    阅读、跑步、摄影
```

- **↑/↓**：在设置项之间移动
- **回车**：编辑当前设置项
- **Home/End**：跳到第一/最后一项
- **q/Esc**：保存并返回

密码字段在显示时以 `•` 遮蔽，编辑时显示明文以便修改。

### WebDAV 同步

按 `[w]` 触发 WebDAV 双向同步。同步完成后显示结果摘要，例如：

```
同步完成: 上传 2 篇 · 下载 3 篇 · 跳过 10 篇 ✓
```

详细同步规则见 [WebDAV 同步规则详解](#webdav-同步规则详解)。

### Flomo 同步

在编辑器中按 **Ctrl+S** 可将当前日记发送到 Flomo。也可在日记列表或阅读模式中对已有日记按 **Ctrl+S** 发送。

发送前需在设置中配置 Flomo 邮箱和密码。日记内容会自动添加 `#日记` 标签。

### AI 提示词

在编辑器中按 **Ctrl+P** 可调用 Deepseek API，根据你在设置中填写的「经历」和「爱好」生成个性化写作提示词。

使用前需在设置中配置 **Deepseek API Key**（可在 [Deepseek 开放平台](https://platform.deepseek.com/) 获取）。

## 文件说明

| 文件/目录 | 说明 |
|-----------|------|
| `~/journal/` | 日记存储目录，所有日记以纯文本保存 |
| `~/journal/YYYY-MM-DD_HHMMSS.txt` | 日记文件，文件名即创建时间 |
| `~/.pjournal` | 配置文件（JSON 格式，权限 600） |
| `~/.pjournal_sync_state` | WebDAV 同步状态文件（记录上次同步时的文件列表，用于删除传播判断） |

### 日记文件格式

每篇日记为纯文本，包含元数据头：

```
日期: 2025-01-15 22:30:00
字数: 256

提示词: 今天我感恩什么？

今天我感恩阳光照在窗台上，温暖而柔和......
```

自由写作的日记则标注为：

```
日期: 2025-01-15 22:30:00
字数: 180

自由写作

今天下了一场大雨，我在窗边看了很久......
```

配置保存在 `~/.pjournal`，为 JSON 格式：

| 键 | 分组 | 说明 |
|----|------|------|
| `deepseek_api_key` | AI | Deepseek API 密钥，用于生成 AI 提示词 |
| `flomo_email` | Flomo | Flomo 登录邮箱 |

| `flomo_token` | Flomo | Flomo 访问令牌（自动管理，无需手动填写） |
| `webdav_url` | WebDAV | WebDAV 服务器地址，如 `https://dav.example.com` |
| `webdav_username` | WebDAV | WebDAV 用户名 |
| `webdav_password` | WebDAV | WebDAV 密码（显示时遮蔽） |
| `personal_experience` | 个人 | 个人经历描述，用于 AI 生成个性化提示词 |
| `personal_hobbies` | 个人 | 个人爱好描述，用于 AI 生成个性化提示词 |

## WebDAV 同步规则详解

同步采用**双向同步**策略，以文件修改时间为判断依据，并参照上次同步状态处理删除。

### 同步流程

```
1. 获取本地文件列表及修改时间
2. 获取远程文件列表及修改时间（PROPFIND）
3. 加载上次同步状态
4. 对所有文件（本地 ∪ 远程）逐一判定：
   ├── 仅本地存在 ──┬─ 上次同步存在 → 本地删除了 → 从远程删除
   │               └─ 首次同步 → 本地新增 → 上传
   ├── 仅远程存在 ──┬─ 上次同步存在 → 远程删除了 → 从本地删除  
   │               └─ 首次同步 → 远程新增 → 下载
   └── 两端都存在 ──┬─ 时间相同（≤1s）→ 跳过
                   ├─ 本地较新 → 上传覆盖远程
                   └─ 远程较新 → 下载覆盖本地
5. 保存新的同步状态
```

### 删除传播

同步状态文件 `~/.pjournal_sync_state` 记录了上次成功同步时的文件列表。通过对比可以判断文件是被有意删除还是新增：

- **本地删除 → 远程删除**：文件在上次同步中存在，现在本地不存在 → 说明用户在本地删除了 → 同步时从远程也删除
- **远程删除 → 本地删除**：文件在上次同步中存在，现在远程不存在 → 说明用户在远程删除了 → 同步时从本地也删除

### 首次同步

如果不存在同步状态文件（首次同步），采用**保守策略**：

- 仅本地存在的文件 → 视为新增 → 上传
- 仅远程存在的文件 → 视为新增 → 下载
- **不会删除任何文件**

### 远程目录结构

日记文件同步到 WebDAV 服务器的 `journal/` 子目录下：

```
WebDAV 根目录/
└── journal/
    ├── 2025-01-14_213000.txt
    ├── 2025-01-15_083000.txt
    └── 2025-01-15_223000.txt
```

### 同步结果消息

| 消息 | 说明 |
|------|------|
| `上传 X 篇` | 本地文件上传到远程 |
| `下载 X 篇` | 远程文件下载到本地 |
| `本地删除 X 篇` | 远程已删除，同步删除本地 |
| `远程删除 X 篇` | 本地已删除，同步删除远程 |
| `跳过 X 篇` | 两端文件一致，无需操作 |
| `失败 X 篇` | 操作失败的文件数 |

## 常见问题

### 终端中文显示乱码

确保终端编码设置为 UTF-8：

```bash
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8
```

### WebDAV 同步提示"请先在设置中配置 WebDAV"

需要在设置界面中填写完整的 WebDAV 服务器地址、用户名和密码。

### WebDAV 同步提示"无需同步，本地和远程一致"

当本地和远程的日记文件完全一致（内容和修改时间相同）时显示此消息。如果预期有差异但仍显示此消息，请检查：

1. WebDAV 地址是否正确（应指向根目录，程序会自动使用 `journal/` 子目录）
2. 用户名和密码是否正确
3. WebDAV 服务是否支持 PROPFIND 请求

### Flomo 发送失败

1. 确认在设置中正确填写了 Flomo 邮箱和密码
2. Flomo token 可能过期，程序会自动重新登录
3. 如果持续失败，检查网络连接和账号状态

### AI 提示词生成失败

1. 确认在设置中填写了有效的 Deepseek API Key
2. API Key 可在 [Deepseek 开放平台](https://platform.deepseek.com/) 获取
3. 检查网络连接是否正常

### 如何备份日记？

日记以纯文本保存在 `~/journal/` 目录，你可以：

1. 直接复制 `~/journal/` 目录到其他位置
2. 使用 WebDAV 同步到云端
3. 使用任何文件备份工具（rsync、Time Machine 等）

### 如何在其他设备上查看日记？

- **WebDAV**：在任何支持 WebDAV 的设备上访问 `journal/` 目录
- **纯文本**：日记为 `.txt` 格式，可用任何文本编辑器打开
- **Flomo**：发送到 Flomo 后可在 Flomo App 中查看

## 技术细节

### 依赖

仅使用 Python 标准库，无第三方依赖：

- `curses` — 终端 UI
- `urllib` — HTTP 请求（WebDAV / Flomo / Deepseek）
- `xml.etree.ElementTree` — 解析 WebDAV PROPFIND 响应
- `json` — 配置文件和 API 交互
- `hashlib` — Flomo 请求签名
- `base64` — HTTP Basic Auth（WebDAV）
- `locale` — 终端本地化
- `datetime` — 日期时间处理

### CJK 字符宽度

程序内置了 CJK 字符宽度计算函数 `char_width()`，根据 Unicode 码点范围判断字符显示宽度（中文等 CJK 字符宽度为 2，ASCII 字符宽度为 1），确保终端中中文排版正确对齐。

### 同步状态管理

同步状态保存在 `~/.pjournal_sync_state`，格式为 JSON：

```json
{
  "2025-01-15_223000.txt": "2025-01-15T14:30:00+00:00",
  "2025-01-14_213000.txt": "2025-01-14T13:30:00+00:00"
}
```

每次同步成功后更新，记录每个文件当时的修改时间（UTC）。下次同步时通过对比此状态判断文件是否被删除。
